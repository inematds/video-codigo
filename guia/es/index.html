En resumen

video-codigo es una skill (un paquete de instrucciones y scripts) para Claude Code y Codex, los agentes de código de Anthropic y OpenAI, que crea videos sin cámara ni editor: cada fotograma se escribe en código (HTML, Canvas o SVG) y se convierte en MP4. Sirve para quien quiere mostrar un producto, un proyecto o una idea en video: lanzamiento, anuncio, explicativo o clase. Si el video lleva narración, la voz se genera en tu computadora, sin pagar por voz, y cada imagen aparece en el instante en que se pronuncia la palabra. Para usarlo, necesitas Node, Python y FFmpeg; para la voz, inemavox con GPU NVIDIA (sin ella, el video sale solo con música).

Qué es

Un director de video dentro de tu agente

La skill pregunta lo que importa, propone la dirección, prueba un fragmento y solo después renderiza el video completo.

🎬 Seis tipos de video

Video de lanzamiento, anuncio con varios ganchos, explicativo de producto, serie de productos con el mismo estilo visual, venta narrada y clase larga.

🎙️ Voz sincronizada con cada palabra

scripts/voz.py genera la narración con tu voz clonada y mide el tiempo de cada palabra. En HTML, pal('frase', 'palavra') indica cuándo aparece cada cosa.

📐 16:9 y 9:16 juntos

El mismo proyecto se adapta a cada formato. Un render para YouTube y otro para Reels, Shorts y TikTok.

Cómo funciona

De la solicitud al MP4

Con voz, el reloj del video es el habla. Sin voz, es la música.

3 preguntas→ roteiro.json→ voz.wav + tiempos→ escenas en HTML→ prueba de 5 s→ MP4 16:9 y 9:16→ revisión

1 · Las preguntas

¿De qué se trata y para quién? (puede ser una carpeta, un repositorio o un sitio web para leer) · ¿Con voz o solo música? · ¿Qué estilo?: el estándar INEMA o un video de referencia.

2 · La voz

Chatterbox dice cada frase con la voz clonada; Whisper escucha, verifica y marca el tiempo de cada palabra. Las frases que salen mal se generan de nuevo.

3 · El renderizado

Un navegador sin ventana abre la página, solicita el fotograma de cada instante (window.seek(t)) y FFmpeg lo une todo con el audio. Sin conexión: las fuentes y las imágenes están en el proyecto.

Requisitos previos

Qué debe estar instalado en la máquina

El instalador comprueba e instala lo que falta, sin sudo.

Node, Python y FFmpeg

Node 18 o posterior, Python 3 con numpy y Pillow, FFmpeg en PATH.

# comprobar
node -v && python3 -V && ffmpeg -version | head -1

Playwright + Chromium

Un navegador sin ventana, controlado por un script, que captura cada fotograma del video. Se instala en ~/.cache.

# se instala automáticamente
bash scripts/preparar-entorno.sh

Voz (opcional, requiere GPU NVIDIA)

La voz usa inemavox instalado en ~/projetos/inemavox: Chatterbox (modelo que habla con una voz copiada de una grabación, la «voz clonada») y Whisper (modelo que escucha el audio y marca el tiempo de cada palabra). También necesitas una grabación limpia de 10–20 s de tu voz en .wav. Sin GPU o sin inemavox, crea videos solo con música.

# los tres deben existir
ls ~/miniconda3/envs/chatterbox/bin/python3 \
   ~/projetos/inemavox/chatterbox_tts_worker.py \
   ~/projetos/inemavox/venv/bin/python
Guía de uso · paso a paso

Tu primer video con código

Lo habitual es pedírselo al agente. Los comandos de abajo son los que ejecuta y te sirven para repetir cualquier etapa a mano. En ellos, $K es la carpeta del kit y $P es la carpeta de tu video:

K=~/projetos/video-codigo                      # dónde se clonó el kit
P=~/videos/trabalho/2026-11-06-meuapp         # una carpeta por video
1

Instala la skill

Clona el repositorio, activa la skill en Claude Code y Codex e instala el navegador para el renderizado.

git clone https://github.com/inematds/video-codigo ~/projetos/video-codigo
bash ~/projetos/video-codigo/instalar.sh  # ✓ skill en ~/.claude/skills/video-codigo
2

Pide el video

Di el tema y, si tienes material, dónde está. El agente hace las tres preguntas que falten. Para narrar con tu voz, dile dónde está la grabación .wav.

/video-codigo haz un video de 40 s de mi app, lee la carpeta ~/projetos/meu-app, narrado con la voz de ~/minha-voz.wav, estilo INEMA
3

Guion con una frase por instante

Archivo $P/roteiro.json. Cada frase tiene un id: es ahí donde se sincroniza la imagen. En voz va la ruta a tu grabación. El dicionario cambia lo que aparece en pantalla por lo que debe leer la voz.

{"id": "meuapp", "pausa": 0.28, "voz": "/home/voce/minha-voz.wav",
 "dicionario": [["16:9", "dezesseis por nove"]],
 "blocos": [{"id": "abertura", "frases": [
   {"id": "hook", "texto": "Este vídeo no tiene cámara."},
   {"id": "codigo", "texto": "Cada fotograma se escribió en código."}]}]}
4

Genera la voz con el tiempo de cada palabra

Se ejecuta en tu computadora. Genera voz.wav y tiempos.js; las frases con menos del 80% de similitud se vuelven a generar automáticamente.

python3 $K/scripts/voz.py --projeto $P $P/roteiro.json  # ej.: meuapp: 41.9 s · 12 frases · 107 palabras
5

Música de fondo

Música original sintetizada (energica 120 BPM, tranquila 84 BPM, o --pista con tu música), 24 dB por debajo de la voz mientras se habla. --lufs -14 es el volumen que esperan YouTube e Instagram. Sin voz, pasa --duracao en segundos.

python3 $K/scripts/mezcla.py --projeto $P --id meuapp --musica tranquila --lufs -14  # → $P/audio/meuapp/mezcla.wav
6

Escenas sincronizadas con el habla

Parte del ejemplo narrado: ya incluye el tema, el motor de tiempo y la estructura (videoSpec, seek, renderReady). Cambia el texto de las escenas y los id de las frases por los de tu guion. Cada elemento aparece cuando se pronuncia la palabra.

cp -r $K/exemplos/explicativo-narrado/{index.html,engine.mjs,motion.mjs,declarativo.mjs,inema} $P/
cp $P/voz/meuapp/tiempos.js $P/   # los tiempos de tu voz
<h1 data-in="hook">Solo código.</h1>
<div data-in="codigo@escrito" data-a="scale">…</div>   <!-- aparece cuando la voz dice "escrito" -->
7

Prueba antes del renderizado completo

Captura fotogramas sueltos en los momentos difíciles, en ambos formatos, y revísalos antes de dedicar tiempo al video completo.

node $K/scripts/render-video.mjs --project $P --output $P/prova.png --still 7.5
node $K/scripts/render-video.mjs --project $P --output $P/prova-v.png --still 7.5 --width 1080 --height 1920
8

Renderizado y revisión

Un MP4 por formato y una hoja de fotogramas para revisar el video completo de una vez.

node $K/scripts/render-video.mjs --project $P --output $P/renders/meuapp-16x9.mp4 --audio $P/audio/meuapp/mezcla.wav
node $K/scripts/render-video.mjs --project $P --output $P/renders/meuapp-9x16.mp4 --width 1080 --height 1920 --audio $P/audio/meuapp/mezcla.wav
python3 $K/scripts/inspect-video.py $P/renders/meuapp-9x16.mp4 --output-dir $P/reviews
Ejemplos

Dos videos hechos con el propio kit

El código, el guion y el audio de cada uno están en exemplos/. Ningún fotograma se filmó. El primer éxito más rápido, sin voz ni GPU: renderiza el ejemplo de lanzamiento.

cd $K/exemplos/lancamento && node ../../scripts/render-video.mjs --project . --output teste.mp4 --audio audio/lancamento/mezcla.wav

En resumen

video-codigo es una skill (un paquete de instrucciones y scripts) para Claude Code y Codex, los agentes de código de Anthropic y OpenAI, que crea videos sin cámara ni editor: cada fotograma se escribe en código (HTML, Canvas o SVG) y se convierte en MP4. Sirve para mostrar un producto, proyecto o idea en video: lanzamiento, anuncio, explicación o clase. Si el video lleva narración, la voz se genera en tu computadora, sin pagar por la voz, y cada imagen aparece justo cuando se pronuncia la palabra correspondiente. Para usarla, necesitas Node, Python y FFmpeg; para la voz, inemavox con GPU NVIDIA (sin ella, el video se genera solo con música).

Qué es

Un director de video dentro de tu agente

La skill pregunta lo necesario, propone la dirección, prueba un fragmento y solo después renderiza el video completo.

🎬 Varios tipos de video

La skill sabe dirigir lanzamientos, anuncios con varios ganchos, explicaciones de productos, series con la misma estética, ventas narradas y clases largas. Ya incluye dos ejemplos listos para copiar: una explicación narrada y un lanzamiento solo con música.

🎙️ Voz sincronizada con cada palabra

scripts/voz.py genera la narración con tu voz clonada y mide la duración de cada palabra. En HTML, pal('frase', 'palabra') indica cuándo aparece cada elemento.

📐 16:9 y 9:16 juntos

El mismo proyecto se adapta a cada formato. Un render para YouTube y otro para Reels, Shorts y TikTok.

Cómo funciona

De la solicitud al MP4

Con voz, el reloj del video es el habla. Sin voz, es la música.

3 preguntas→ roteiro.json→ voz.wav + tiempos→ escenas en HTML→ prueba de 5 s→ MP4 16:9 y 9:16→ revisión

1 · Las preguntas

¿De qué trata y para quién es? (puede ser una carpeta, un repositorio o un sitio web para leer) · ¿Con voz o solo con música? · ¿Qué estilo? — el estilo predeterminado de INEMA o un video de referencia.

2 · La voz

Chatterbox pronuncia cada frase con la voz clonada; Whisper escucha, verifica y marca la duración de cada palabra. Las frases que salen mal se vuelven a generar.

3 · El render

Un navegador sin ventana abre la página, solicita el fotograma de cada instante (window.seek(t)) y FFmpeg lo une todo con el audio. Sin conexión: las fuentes y las imágenes quedan en el proyecto.

Requisitos previos

Qué debe haber en la máquina

El instalador (instalar.sh) instala Playwright y Chromium por sí solo, sin sudo. Solo comprueba el resto y muestra el comando para instalarlo.

Node, Python y FFmpeg

Node 18 o posterior, Python 3 con numpy, scipy y Pillow, y FFmpeg en el PATH.

# comprobar
node -v && python3 -V && ffmpeg -version | head -1
# bibliotecas de Python
python3 -m pip install --user numpy scipy pillow

Playwright + Chromium

Un navegador sin ventana, controlado por script, que captura cada fotograma del video. Se instala en ~/.cache.

# instalar.sh (paso 1) ya ejecuta esto
bash ~/projetos/video-codigo/scripts/preparar-entorno.sh

Voz (opcional, requiere GPU NVIDIA)

La voz usa inemavox, instalado en ~/projetos/inemavox: Chatterbox (modelo que habla con una voz copiada de una grabación, la «voz clonada») y Whisper (modelo que escucha el audio y marca la duración de cada palabra). También necesitas Miniconda (gestor de entornos Python) y una grabación nítida de 10–20 s de tu voz en .wav. La primera vez, los modelos descargan varios GB. Si tienes conda o inemavox en otra ubicación, indica la ruta con CHATTERBOX_PYTHON=/caminho/python3 y INEMAVOX_DIR=/caminho/inemavox. Sin GPU o sin inemavox, crea videos solo con música.

# deben existir los tres
ls ~/miniconda3/envs/chatterbox/bin/python3 \
   ~/projetos/inemavox/chatterbox_tts_worker.py \
   ~/projetos/inemavox/venv/bin/python
# instalar (probado: Python 3.11, chatterbox-tts 0.1.6)
git clone https://github.com/inematds/inemavox ~/projetos/inemavox
conda create -n chatterbox python=3.11 -y
~/miniconda3/envs/chatterbox/bin/pip install chatterbox-tts==0.1.6
cd ~/projetos/inemavox && python3 -m venv venv && venv/bin/pip install faster-whisper soundfile numpy
Guía de uso · paso a paso

Tu primer video con código

Lo habitual es pedirlo directamente al agente (paso 2): escribe el guion y las escenas, y ejecuta todo. Los comandos de los pasos siguientes son los que ejecuta el agente y te sirven para repetir una etapa manualmente. Para eso, ejecuta primero en la terminal ($K es la carpeta del kit y $P, la de tu video):

K=~/projetos/video-codigo                      # donde se clonó el kit
P=~/videos/trabalho/2026-11-06-meuapp         # una carpeta por video
mkdir -p "$P"
1

Instala la skill

Clona el repositorio, activa la skill en Claude Code y Codex e instala el navegador para el render.

git clone https://github.com/inematds/video-codigo ~/projetos/video-codigo
bash ~/projetos/video-codigo/instalar.sh  # ✓ skill en ~/.claude/skills/video-codigo

Prueba la instalación renderizando el ejemplo listo (no requiere voz ni GPU; tarda alrededor de 1 minuto):

cd ~/projetos/video-codigo/exemplos/lancamento && node ../../scripts/render-video.mjs --project . --output teste.mp4 --audio audio/lancamento/mezcla.wav --overwrite
2

Pide el video

Di el tema y, si tienes material, indica dónde está. El agente te hará las tres preguntas que falten. Para narrarlo con tu voz, dile dónde está la grabación .wav.

/video-codigo haz un video de 40 s de mi app, lee la carpeta ~/projetos/meu-app, narrado con la voz de ~/minha-voz.wav, estilo INEMA
↷

¿Sin voz? El reloj es la música

Sin narración no necesitas guion ni GPU. Lo más sencillo es pedirle al agente («solo con música, 20 s»): él escribe las escenas. Si quieres partir del ejemplo de lanzamiento manualmente, mira qué debes cambiar en el <script> de index.html:

• window.videoSpec = {… duration: 21} — la duración del video en segundos; usa la misma que la música.
• SEG — la lista de etapas: a y b son los segundos en que cada etapa aparece y desaparece; rot y sub son el título y la línea de abajo.
• S — dónde está y qué tamaño tiene la forma amarilla en cada segundo (t), que conecta una etapa con la siguiente.
• function conteudo — el dibujo dentro de la forma en cada etapa (módulos, página, play, terminal, conversación). Cámbialos por los de tu producto.

cp -r $K/exemplos/lancamento/{index.html,motion.mjs,inema} $P/
python3 $K/scripts/mezcla.py --projeto $P --id meuapp --duracao 21 --musica energica --lufs -14  # misma duración que videoSpec

Después ve al paso 7 (prueba) y al 8 (render, con --audio $P/audio/meuapp/mezcla.wav).

3

Guion con una frase por instante

Archivo $P/roteiro.json. Cada frase tiene un id: es donde se sincroniza la imagen. En voz va la ruta de tu grabación. dicionario reemplaza lo que aparece en pantalla por lo que debe leer la voz.

{"id": "meuapp", "pausa": 0.28, "voz": "/home/voce/minha-voz.wav",
 "dicionario": [["16:9", "dezesseis por nove"]],
 "blocos": [{"id": "abertura", "frases": [
   {"id": "hook", "texto": "Este vídeo não tem câmera."},
   {"id": "codigo", "texto": "Cada quadro foi escrito em código."}]}]}
4

Genera la voz con la duración de cada palabra

Se ejecuta en tu computadora. Genera $P/voz/meuapp/voz.wav y $P/voz/meuapp/tiempos.js (la duración de cada palabra); las frases por debajo del 80 % de similitud se regeneran automáticamente.

python3 $K/scripts/voz.py --projeto $P $P/roteiro.json  # ej.: meuapp: 41.9 s · 12 frases · 107 palabras
5

Música de fondo

Música original sintetizada (energica, 120 pulsos por minuto; tranquila, 84; o --pista con tu música), 24 dB por debajo de la voz mientras habla. --lufs -14 deja el volumen final al nivel que usan YouTube e Instagram (así, la plataforma no baja ni satura el sonido). Sin voz, pasa --duracao en segundos.

python3 $K/scripts/mezcla.py --projeto $P --id meuapp --musica tranquila --lufs -14  # → $P/audio/meuapp/mezcla.wav
6

Escenas sincronizadas con la voz

Parte del ejemplo narrado: ya incluye el tema, el motor de tiempo y la estructura que usa el render (videoSpec = tamaño y duración, seek(t) = dibuja el instante t, renderReady = avisa cuando cargaron las fuentes y las imágenes). Cambia el texto de las escenas y, en cada pal('frase', 'palabra'), ini('frase') y data-in, los id y las palabras por los de tu guion. Si queda alguno del ejemplo, el render se detiene y te dice cuál: Não encontrei «câmera» na frase hook do roteiro.

cp -r $K/exemplos/explicativo-narrado/{index.html,engine.mjs,motion.mjs,declarativo.mjs,inema} $P/
cp $P/voz/meuapp/tiempos.js $P/   # los tiempos de tu voz
<h1 data-in="hook">Solo código.</h1>
<div data-in="codigo@escrito" data-a="scale">…</div>   <!-- aparece cuando la voz dice "escrito" -->
7

Prueba antes de renderizar todo

Captura fotogramas sueltos en los momentos difíciles, en ambos formatos, y revísalos antes de dedicar tiempo al video completo. --still indica el segundo del video (debe estar dentro de la duración; en un guion de 5 s, usa 2 o 3).

node $K/scripts/render-video.mjs --project $P --output $P/prova.png --still 2
node $K/scripts/render-video.mjs --project $P --output $P/prova-v.png --still 2 --width 1080 --height 1920
8

Render y revisión

Un MP4 por formato y una hoja de fotogramas para revisar todo el video de una vez.

node $K/scripts/render-video.mjs --project $P --output $P/renders/meuapp-16x9.mp4 --audio $P/audio/meuapp/mezcla.wav
node $K/scripts/render-video.mjs --project $P --output $P/renders/meuapp-9x16.mp4 --width 1080 --height 1920 --audio $P/audio/meuapp/mezcla.wav
python3 $K/scripts/inspect-video.py $P/renders/meuapp-9x16.mp4 --output-dir $P/reviews
